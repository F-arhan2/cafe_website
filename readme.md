# ☕ MochaMuse Cafe Website

A modern and responsive café website built using HTML and CSS. The website showcases the café's brand, menu offerings, operating hours, location, and social media presence through an attractive and user-friendly interface.

## 🚀 Features

* Responsive design for desktop and mobile devices
* Smooth navigation bar with section links
* Café operating hours display
* Coffee menu showcase with images
* Café location integration using Google Maps
* Contact section for customer inquiries
* Social media links (Instagram, LinkedIn, YouTube)
* Modern and clean UI design

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts
* Responsive Web Design

## 📸 Website Sections

### Home

Displays café timings and welcomes visitors.

### About Us

Dedicated section for café information and brand story.

* Crema Espresso

* Caramel Latte
* Mocha Latte
* Affogato

### Location

Provides a direct link to the café's location on Google Maps.

### Contact

Allows visitors to reach out for inquiries and information.

### Footer

Contains social media links and additional navigation options.

## ▶️ How to Run

1. Download or clone the repository:

```bash
git clone https://github.com/your-username/mochamuse-cafe-website.git
```

2. Open the project folder.

3. Open `index.html` in any modern web browser.

No additional installation or dependencies are required.
